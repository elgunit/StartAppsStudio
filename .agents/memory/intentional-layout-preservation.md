---
name: Preserve intentional page layouts
description: Keep responsive fixes local to the issue and retain established page compositions.
---

The Start Apps Studio page's established section compositions were intentionally designed. Responsive fixes should preserve the existing composition unless the user asks for a redesign.

**Why:** A broad pricing-grid reflow made the page look worse than its prior design, and the user called out the change.

**How to apply:** For a responsive defect, keep the desktop composition intact and fix wrapping, alignment, and narrower breakpoints locally. Reorganize the overall grid only when requested or when the current structure cannot meet the requirement.
